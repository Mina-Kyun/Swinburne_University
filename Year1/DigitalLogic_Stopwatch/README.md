**# Custom Digital Stopwatch (Logisim)**



## Course Information




\- Course: Digital Logic Design  

\- Institution: Swinburne University

\- Type: Coursework Assignment



This project implements a customised digital stopwatch using digital logic components in Logisim.



The system is designed using a modular digital architecture consisting of five stages:

\- Master Control

\- Seconds Units Counter

\- Seconds Tens Counter

\- Minutes Counter

\- Split Storage System



**## Key Features**



\- Ripple counter architecture (Mod-10 and Mod-6 counters)

\- T Flip-Flop start/stop control

\- Custom preset reset value (08:00)

\- Hardware split storage limit (5 splits)

\- Clock gating using logic gates

\- Register-based stable data storage
