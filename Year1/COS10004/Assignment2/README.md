# Matchsticks Game (ARM Assembly)

This project implements a matchsticks game using ARM Assembly in the ARMLite environment.

The system is designed as a multi-stage program with progressive functionality:

- Stage 1 – Player setup (name and matchsticks input)
- Stage 2 – Player interaction and input validation
- Stage 3 – Game logic and turn-based mechanics
- Stage 4 – Graphics rendering (matchsticks display)

## Key Features

- User input handling (player name and matchstick count)
- Input validation (range 10–100 for matchsticks)
- Turn-based matchstick removal (1–7 per turn)
- Game loop with dynamic state updates
- Win / lose / draw conditions
- Computer opponent (randomized moves)
- Graphical rendering of matchsticks using pixel-based drawing
